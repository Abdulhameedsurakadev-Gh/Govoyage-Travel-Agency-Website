# Govoyage-Travel-Agency-Website

Govoyage is a responsive travel agency website that allows users and tourists to explore destinations easily using a **search bar, filters, and pagination**. The project focuses on applying real-world **JavaScript logic** to build interactive and user-friendly features.

## Live Demo
👉 https://govoyageafrica-travel-agency-website.netlify.app/

## 🛠️ Built With
- HTML5
- CSS3 / Tailwind CSS
- JavaScript (ES6+)

##  Features
- 🔍 Search functionality to quickly find destinations  
- 🎯 Filter destinations by category  
- 📄 Pagination for better data organization and performance  
- 📱 Fully responsive design (mobile, tablet, desktop)  
- ⚡ Dynamic content rendered with JavaScript  

## 🧠 What I Learned
- Writing clean and reusable JavaScript functions  
- Implementing search, filter, and pagination logic  
- Debugging real-world JavaScript issues  
- Managing UI state efficiently  
- Structuring a front-end project for scalability
